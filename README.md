# Go Pet Shop

Учебный backend-проект интернет-магазина товаров для животных на Go.

В рамках задания проект будет доработан в двух версиях.

## V1

В ветке `v1` будут добавлены unit-тесты для Product handlers:

- CreateProduct
- UpdateProduct
- DeleteProduct

Будут проверяться успешные запросы, некорректные данные и внутренние ошибки.

## V2

В ветке `v2` тестирование будет доработано с использованием mock для слоя storage.

Mock позволяет тестировать handlers изолированно, без подключения к реальной базе данных.

## Branches

- `main` — исходный проект
- `v1` — unit tests
- `v2` — tests with mock
